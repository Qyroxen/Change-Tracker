# Change-Tracker

Track system changes

## Features

- Easy-to-use CLI interface
- Fast and efficient processing
- Cross-platform support

## Installation

```bash
git clone https://github.com/Qyroxen/Change-Tracker.git
cd Change-Tracker
go build -o change-tracker .
```

## Usage

```bash
.change-tracker .
.change-tracker --path ./src
```
